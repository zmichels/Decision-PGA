# Security Policy

Decision-PGA is a local research prototype. It does not require external model
API calls, credentials, or network services for its core tests and examples.

## Reporting A Security Issue

Please do not open a public issue containing credentials, private data,
protected health information, proprietary documents, or other sensitive
material. Instead, contact the repository owner directly through GitHub.

## Data Handling Expectations

- Use synthetic or explicitly public examples.
- Do not commit secrets, API keys, private documents, patient data, or provider
  responses that may contain sensitive content.
- Treat generated diagnostic reports as local artifacts unless they have been
  reviewed for disclosure risk.
