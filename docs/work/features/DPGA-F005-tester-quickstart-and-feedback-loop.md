# DPGA-F005: Tester Quickstart And Feedback Loop

## Description

Make the repository easy for a small number of testers to clone, run,
evaluate, and critique without requiring model credentials.

## Acceptance Criteria

- [x] A 20-minute tester guide is available.
- [x] Focused feedback prompts are available.
- [x] Tester example payloads cover stable, ambiguous, diffuse, regime-shift, and provider-score inputs.
- [ ] Feedback from two testers is collected and triaged.
