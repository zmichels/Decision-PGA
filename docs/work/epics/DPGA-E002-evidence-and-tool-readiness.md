# DPGA-E002: Evidence And Tool Readiness

## Description

Move Decision-PGA from a working prototype toward a more credible, shareable,
agent-usable diagnostic by adding a reproducible evaluation harness, tester
quickstart material, and a local MCP server.

## Acceptance Criteria

- [x] A deterministic benchmark compares PGA diagnostics against entropy, margin, and drift baselines.
- [x] Private-repo tester docs and example payloads are available.
- [x] A local stdio MCP server exposes read-only Decision-PGA diagnostic tools.
- [ ] Feedback from at least two testers is reviewed and converted into follow-up work.
